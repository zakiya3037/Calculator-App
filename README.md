# Modern Calculator 🧮

A simple and modern calculator built using **HTML, CSS, and JavaScript**. It provides a clean user interface, interactive buttons, hover effects, and keyboard support for performing basic mathematical calculations.

## ✨ Features

- **Basic Operations:** Addition, subtraction, multiplication, and division.
- **Percentage:** Convert a number into a percentage.
- **Positive and Negative Numbers:** Change the sign of a number.
- **Clear Button:** Reset the calculator.
- **Backspace:** Remove the last entered digit.
- **Decimal Support:** Perform calculations with decimal numbers.
- **Keyboard Support:** Use your keyboard to enter numbers and operators.
- **Error Handling:** Displays an error message when dividing by zero.
- **Modern UI:** Gradient background, rounded buttons, hover effects, and smooth animations.
- **Responsive Design:** Works on different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Structures the calculator.
- **CSS3** — Adds styling, layout, hover effects, animations, and responsiveness.
- **JavaScript** — Handles user interactions and performs calculations.

## 🚀 How to Run the Project

1. Download or clone the project to your computer.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start performing calculations!

No additional libraries or installations are required.

## ⌨️ Keyboard Shortcuts

| Key | Function |
|---|---|
| `0–9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `.` | Enter a decimal point |
| `Enter` or `=` | Calculate the result |
| `Backspace` | Remove the last digit |
| `Escape` or `Delete` | Clear the calculator |
| `%` | Calculate a percentage |
